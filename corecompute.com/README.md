# CoreCompute EB-5 数据中心项目网站

这是一个专业的EB-5投资项目企业网站，用于展示"核心算力数据中心"项目的详细信息。

## 网站结构

### 主要页面

1. **首页** - 项目核心亮点展示
   - 首屏英雄区
   - 四大核心优势
   - 全球名额告示
   - 信任背书

2. **项目详情** - 全面项目介绍
   - 市场机遇
   - 项目介绍（佐治亚州四大优势）
   - 项目方实力
   - 项目时间表

3. **投资与风控** - 投资安全保障
   - 融资结构
   - 风控措施（四项核心风控）
   - 就业创造（294个岗位）
   - 退出机制

4. **EB-5移民通道** - 移民政策解读
   - 新法优势
   - TEA乡村地区介绍
   - 区域中心介绍
   - 移民流程

5. **关于我们** - 团队与合作伙伴
   - 项目管理团队
   - 合作伙伴

6. **资料下载** - 项目资料
   - EB-5项目备忘录
   - 商业计划书摘要
   - 常见问题解答

7. **联系我们** - 咨询通道
   - 咨询表单
   - 联系方式

## 文件说明

- `index.html` - 主HTML文件，包含所有页面内容
- `styles.css` - 样式文件，包含所有CSS样式
- `script.js` - JavaScript文件，包含交互功能

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可查看网站
2. 或者使用本地服务器运行（推荐）：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx http-server
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 自定义说明

### 替换占位图片
网站中包含多个占位图片区域，您需要：
1. 准备实际的项目图片
2. 替换HTML中的 `.placeholder-image` 部分
3. 或添加实际的 `<img>` 标签

### 更新联系信息
在 `index.html` 的"联系我们"部分更新：
- 邮箱地址
- 电话号码
- 项目地址

### 添加实际资料
在"资料下载"部分，需要：
1. 准备PDF文件
2. 更新下载链接指向实际文件
3. 添加FAQ内容

3. 确保所有声明符合法规要求
